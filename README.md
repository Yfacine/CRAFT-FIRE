# CRAFT-FIRE

![소방설비 설계 · CRAFT-FIRE의 흑백 표지](https://raw.githubusercontent.com/Yfacine/Yfacine/4225c2a517e5917cab196b11c5817a3ab532f08d/assets/repositories/CRAFT-FIRE.webp)

AutoCAD 2024에서 소방설비 설계 기능을 개발하기 위한 기반을 구축하고 있습니다.

**현재 상태 · 개발 중 · 기반 구축 · 소방 설계 기능 구현 전**

## 01 / 공개 범위

AutoCAD 2024용 Windows x64 개발 프로젝트의 첫 공개 소스 스냅샷입니다. 제품 버전은 [version.json](version.json)의 0.1.0이며, 첫 사전 릴리스 태그는 v0.1.0-dev.1입니다.

AutoCAD 연결부와 기능 대기 목록, 진단 명령 PASSAIFIRE_ABOUT 및 PASSAIFIRE_STATUS를 포함합니다.

- 현재 구성은 [구조 문서](docs/ARCHITECTURE.md)에 있습니다.
- 공개 범위는 소스, 개발·검사 스크립트, 빌드 설정과 선별한 문서입니다.
- 첨부 ZIP은 소스 스냅샷입니다. 독립 빌드, 설치 및 실제 CAD 시험은 이번 공개에서 미실행입니다.

## 02 / 다음 단계
